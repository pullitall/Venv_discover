Venv Discover — User Guide

Complete, self-contained offline user guide for finding, inspecting, and safely cleaning Python virtual environments.

1. What It Is

Venv Discover finds every Python environment on your PC, shows exactly how big each one is and what's inside, and cleans up safely. Everything runs completely locally on your computer with zero internet access, zero third-party dependencies, and zero tracking.

2. Starting It

To start the app, double-click VenvDiscover.exe. There is nothing to install, and no Python installation is needed on your PC.

First Launch on Windows: Because Venv Discover is a free independent application that is not signed with a commercial code-signing certificate, Windows SmartScreen will show: "Windows protected your PC".

3. The Main Window

The application is organized into two primary tabs:

  • Environments tab: Displays all discovered virtual environments and installations across all scanned drives.
  • Bin tab: Holds deleted environments that were moved into the 14-day safety recycle bin, allowing one-click restoration.
Figure 1: Main window displaying the Environments table, package inspector panel, search, top and bottom action bars, and status line.

Key Window Areas

  1. Top Bar: Contains the Search box (type a package name to find environments), the Rescan button, Clean conda cache, and ⚙ Settings.
  2. Environments Table: Lists every discovered environment with 7 clear columns: Name, Kind, Python, Packages, Size, Last used, and Location. Click any column heading to sort.
  3. Packages Panel (Right): Selecting an environment row instantly displays its installed libraries, versions, and installation sources (pip or conda).
  4. Bottom Action Bar: Convenient buttons for the selected environment: Open folder, Copy activate command, Copy path, Open terminal with terminal picker dropdown (▾), and Delete… at the far right.
  5. Status Line: Displays background scan progress or total environments found (e.g. Found 5 envs in 0.4 s) and a theme button (e.g. Dark · Default) that opens Settings when clicked.

4. Finding What Takes Space

Virtual environments can quietly accumulate gigabytes of disk space. To find what is taking up space:

  • Sort by Size: Click the Size column header. The largest environments immediately sort to the top.

Understanding Environment Kinds

Kind Description Status & Deletion
conda base Root installation of Anaconda or Miniconda. (locked) Protected; cannot be deleted in Venv Discover.
conda Isolated Conda environment located inside an envs/ directory. Can be deleted if you no longer need it (note: Conda shares files with its package cache, so deleting may free less space than displayed).
venv Standard virtual environment created with python -m venv or virtualenv. Can be deleted if you no longer need it.
python install System Python interpreter installation (e.g. C:\Python312 or Programs\Python). (locked) Protected; cannot be deleted in Venv Discover.
temp Ephemeral virtual environment created in temporary directories (e.g. pipx, test runners). Can be deleted if you no longer need it.
app-owned Virtual environment bundled inside another software application's directory. Caution: Deleting an environment another program uses breaks that program!
What does "(locked)" mean? Core Python installations (python install) and Conda base distributions (conda base) are marked as (locked). Venv Discover protects them from deletion so you never accidentally corrupt your operating system or system-wide toolchains.

Which Tools Does It Find?

Venv Discover automatically discovers virtual environments and Python installations created by virtually every modern Python workflow tool:

  • Standard Tools: Standard venv and virtualenv directories across all project folders and local drives.
  • Conda & Mamba Ecosystem: Anaconda, Miniconda, micromamba, and Mamba 2.x installations, environments listed across all Conda configuration files (.condarc, condarc.d, .mambarc, CONDA_ENVS_PATH, CONDA_ENVS_DIRS), and registry-registered Conda distributions.
  • Pixi: Global and project environments created with Pixi (with package records or pixi metadata).
  • Modern Packaging Managers: Environments managed by Hatch (including HATCH_DATA_DIR virtualenvs up to 3 levels deep and standalone Pythons), PDM (shared venvs and custom venv.location), Poetry, and Rye (tool envs and installed Pythons).
  • Application Runners: Isolated application environments from pipx (including modern defaults under %LOCALAPPDATA%\pipx\venvs and %PIPX_HOME%) and uv.
  • Locked Base Pythons: System Python interpreters, pyenv-win, Windows Store Pythons, Hatch Pythons, and Rye Pythons (always kept locked to prevent accidental deletion).

Package-Manager Caches

Besides virtual environments, Python tools accumulate massive package caches containing downloaded wheels, source tarballs and build artifacts. Click Caches… on the top bar or in Settings to discover and clean them:

Figure 3: Package-manager caches dialog displaying discovered caches for uv, pip, poetry, and pipenv with sizes and safe clean options.

The dialog identifies cache folders for uv, pip, poetry, and pipenv, respecting custom environment variable overrides (such as UV_CACHE_DIR, POETRY_CACHE_DIR, PIPENV_CACHE_DIR, or PIP_CACHE_DIR). When you select a cache and click Clean…:

  • A confirmation dialog indicates the exact space to be freed and explains that packages will be automatically re-downloaded when required.
  • If the tool is installed on your system PATH, Venv Discover streams its native cleaning command (e.g. uv cache clean, pip cache purge, poetry cache clear, or pipenv --clear) directly into a progress window.
  • If the tool is no longer installed, the cache contents are safely removed via temporary rename. Poetry's virtual environments (virtualenvs\) and uv's Python installations are strictly protected and never touched.

5. Looking Inside Environments

You never have to guess what an environment was used for. Click any row in the table, and the right-hand panel instantly parses and presents its packages:

  • Packages Panel: Lists package names, versions, and installer origin (pip or conda) read directly from .dist-info and conda-meta files on disk without launching slow subprocesses.
  • Search across all environments: The top search bar matches package names only across all environments (e.g. type numpy, torch, or fastapi to see every environment that contains that package). It does not search folder names, paths, or Python versions.
  • Copy package list: Right-click any environment and select Copy package list to copy all installed packages as clean name==version lines (standard requirements.txt format) directly to your clipboard.

6. Quick Actions in Plain Words

Every everyday workflow is reachable with a single click or keyboard shortcut:

  • Copy path (Ctrl+C): Copies the selected environment's folder path to your clipboard. (This is the only keyboard shortcut in the app).
  • Copy Python path: Copies the direct path to python.exe within the environment, perfect for pasting into VS Code, PyCharm, or configuration files.
  • Copy activate command: Copies the exact command needed to activate the environment in your shell (e.g. call ...\activate.bat or conda activate ...).
  • Open terminal: Opens your favorite command line terminal with the environment pre-activated. Use the small dropdown arrow (▾) to switch between installed terminals.
  • Right-click menu: Right-clicking any row opens a context menu with all of these actions plus Open folder and Copy package list.

For Scripts and Automation

The same engine powering the graphical interface can be used directly from scripts and AI agents via the command line:

  • VenvDiscover.exe --json outputs a single, structured JSON document containing all discovered environments.
  • --known-only skips drive scanning and reads only registered environment locations (completing in under 1 second).
  • --packages includes full package lists for each environment.
  • --sizes measures on-disk directory sizes and last used timestamps.
  • --search NAME[==VER] filters environments containing a specific package.
  • --paths DIR... restricts scanning to designated directories.
Important for Terminal Users: Because VenvDiscover.exe is built as a windowless Windows application (to prevent empty console windows from flashing when launched from desktop shortcuts), typing a bare command directly in a terminal without redirection returns immediately with no output. To capture or view command-line output, run it from a script, pipe it (e.g. VenvDiscover.exe --json | ConvertFrom-Json or | Out-Host in PowerShell), or redirect it to a file (VenvDiscover.exe --json > envs.json).

7. Deleting Safely

The Golden Rule: If you're not sure, don't delete! Deleting an environment another program uses (such as AI image generators, editors, or games' tools) breaks that program until that program rebuilds the environment.
Figure 2: Delete confirmation dialog showing the permanent deletion warning for an environment over 1 GB, 14-day bin moves, and locked protection.

How Deletion Works

  • The 14-Day Safety Bin (Environments up to 1 GB): Environments up to 1 GB (1,073,741,824 bytes) are moved into a local .venvdiscover-bin folder on that same drive. They are kept for 14 days. You can switch to the Bin tab at any time and click Restore to restore them to their original location.
  • Permanent Deletion (Environments over 1 GB): Environments larger than 1 GB cannot be moved to the recycle bin. They are deleted permanently so that disk space is freed at once. The dialog explicitly warns you: "This is X.X GB and can only be deleted permanently."
  • Locked Items: Python base installations (python install) and Conda base distributions (conda base) cannot be deleted.

8. Settings & Personalization

Open Settings by clicking ⚙ Settings in the top bar or clicking the theme indicator on the status bar:

  • Themes: Choose between Dark, Light, or Match Windows (automatically follows your system dark/light mode preference).
  • Palettes: Select from 4 curated palettes — Default, Night city, Calm glass, or Bold editorial.
  • Drives to scan: Click the Drives… button inside Settings to choose which local drives to scan or uncheck specific drive letters.
  • Terminal: not part of Settings. Pick it with the small arrow (▾) on the Open terminal button (Command Prompt, Windows PowerShell, PowerShell 7, Windows Terminal, or Git Bash). Only terminals actually installed on your PC appear, and your choice is remembered.

9. Where Data Lives & Uninstallation

Venv Discover operates completely standalone. It never touches the Windows Registry and creates zero background services:

  • Configuration & Cache: Stored in %LOCALAPPDATA%\VenvDiscover (including settings.json, cache.json, and actions.log).
  • Recycle Bins: Binned environments reside in a hidden .venvdiscover-bin directory at the root of each scanned drive.
  • Complete Removal: To remove the app completely, simply delete the folder containing VenvDiscover.exe, delete %LOCALAPPDATA%\VenvDiscover, and empty/delete any .venvdiscover-bin folders on your drives (which permanently deletes anything still in the bin).

10. Frequently Asked Questions (FAQ)

Q: The application found zero environments on my PC.

If nothing is found, either Python is not installed on this PC, or your environments reside on a drive that is unchecked. Open ⚙ Settings → Drives… to verify that your drives are selected for scanning.

Q: Why was the scan slow?

The first scan of a large hard disk with hundreds of thousands of files must walk folder structures on disk. On large drives, this can take around one minute. Subsequent launches immediately show the last scan's results from cache and rescan in the background.

Q: "Open terminal" opened the wrong terminal.

Click the arrow (▾) next to the Open terminal button to choose another installed terminal (Command Prompt, Windows PowerShell, PowerShell 7, Windows Terminal, or Git Bash). Your choice is saved automatically.
